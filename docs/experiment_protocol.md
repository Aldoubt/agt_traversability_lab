# Experiment Protocol

All experiments should be reproducible.

Each experiment contains:

```
EXPXXX_name/
├── README.md
├── config/
├── command.sh
├── results/
└── conclusion.md
```

Required records:

- Dataset information
- Software environment
- Algorithm configuration
- Execution command
- Visualization outputs
- Evaluation metrics
- Experimental conclusion

Results should explain not only what happened, but why a method succeeds or fails in agricultural environments.
